Privacy Policy

Last updated: October 2026

Channel Uploader is a private application operated by Rest and Relaxation. Its only purpose is to upload videos to the operator's own YouTube channel.

What data it uses

The application uses the YouTube Data API to upload videos, set thumbnails and add videos to playlists on the operator's own channel. It signs in with the operator's own Google account only. It does not access, collect or store data about any other person or account.

How data is stored

The sign-in token is stored privately by the operator and is used only to upload the operator's videos. No data is sold, shared with third parties, or used for advertising.

YouTube and Google

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
